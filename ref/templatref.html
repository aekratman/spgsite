What is this?

I've always found it useful to have a template to start with when I'm putting together a new website. I'm also constantly forgetting the exact syntax of certain things I don't use often. So... I put together this template/cheat sheet!

Please steal this template! That's why I made it! I want to help people get started on their websites. I'd really appreciate a link back to birdrobot.party if you find this useful, but credit is not mandatory.

Right click and select "view page source" to grab the code, or click here to download template.html.

About the CSS for this page itself...

line-height: 1.5em;
I think that somewhere around 1.5 or 1.6em is ideal for readability.

grid:
"header header header" auto
"leftSide body rightSide" 1fr
"footer footer footer" auto
/ 25% 50% auto;
The bolded numbers here specify that the left column must take up 25% of the screen, the middle must take up 50%, and the right column should just align itself with them using what space is left over.

This, on the other hand...
/ auto 50% auto;
...would make it so the middle column must take up 50%, and the sidebars divide the remaining space between them based on what they contain.

CSS Reference

Backgrounds
background-color: #fff;
background-image: url("image.png");
background-repeat: no-repeat | repeat | repeat-y | repeat-x;
background-position: top left | bottom right | center;
background-attachment: fixed | scroll;
To change opacity of a div's background but not the text or other elements, use RGBA values.
background: rgba(154, 205, 50, 0.3);
Borders
Order for values: top, right, bottom, left
If 3 values, defines top, right/left, and bottom. If 2 values, defines top/bottom and right/left.
border: 5px solid #E874A5;
border-radius: 25px;
border-style: dotted | dashed | double | groove | ridge | inset | outset | none | hidden;
border-width: 4px;

Images
Fill: default; distorts image to fill container.
Cover: fill the container; preserves the aspect ratio by cropping.
Contain: does the same, but does not cut content.
object-fit: fill | cover | contain;
Basic gallery with uniform thumbnails:

}

}

☀ Tip

A pixel measurement is fixed, while a percentage is relative to the size of the viewer's browser window.

☀ Tip

I wanted to put all the basics in one file for reference, but you should generally keep your CSS in a separate file so you can easily apply the styling to multiple pages.

To do that, put the following in the <head> tag: <link href="css/style.css" rel="stylesheet" type="text/css" media="all">

☀ Tip

You can make HTML code visible as text by using the unicode character for at least one of the brackets: &lt; for < and &gt; for >.
